Sorting Algorithms

Bubble Sort

Bubble Sort is a simple sorting algorithm that repeatedly steps through the list, compares adjacent elements and swaps them if they are in the wrong order.

How does Bubble Sort Algorithm Work?

Bubble Sort works by comparing adjacent elements and swapping them if they are in the wrong order. This process causes larger values to "bubble" to the end of the list with each iteration.

There are mainly three steps in the algorithm:

1. Traverse: Start from the first element and move toward the last.

2. Compare & Swap: Compare the current element with the next one. If the current element is greater, swap them.

3. Repeat: Continue this for each pair. After one full pass, the largest element is guaranteed to be at the end.

Big O Complexity
  • Best: O(n) when the array is already sorted.
  • Average: O(n2) for random or mixed input.
  • Worst: O(n2) when the array is sorted in reverse.
  • Space: O(1) auxiliary (swapping happens in-place).

    Selection Sort

    Selection Sort is a simple comparison-based sorting algorithm that divides the input list into two parts: a sorted sublist of items which is built up from left to right at the front (left) of the list and a sublist of the remaining unsorted items that occupy the rest of the list.

    How does Selection Sort Algorithm Work?

    The visualization below demonstrates the selection sort process, where we repeatedly select the smallest (or largest) element from the unsorted portion and move it to the sorted portion.

    There are mainly three steps in the algorithm:

    1. Find the Minimum: Scan the unsorted part of the array to find the smallest element.

    2. Swap: Swap the found minimum element with the first element of the unsorted part.

    3. Repeat: Repeat the process for the remaining unsorted part of the array.

    4. Base Case: The process continues until the entire array is sorted, with each pass reducing the unsorted portion by one element.

    Big O Complexity
    • Best: O(n2) due to nested loops.
    • Average: O(n2) for all cases.
    • Worst: O(n2) even for sorted input.
    • Space: O(1) as it sorts in-place.

      Insertion Sort

      Insertion Sort builds a sorted section by repeatedly inserting the next element into its correct position.

      How does Insertion Sort Algorithm Work?

      Insertion Sort takes one element at a time and inserts it into the already-sorted portion of the list, shifting larger values to the right.

      There are mainly four steps in the algorithm:

      1. Start: Treat the first element as sorted.

      2. Select: Pick the next element as the key.

      3. Shift: Move larger elements one position to the right.

      4. Insert: Place the key in its correct position.

      Big O Complexity
      • Best: O(n) when the array is already sorted.
      • Average: O(n2) for random input.
      • Worst: O(n2) when the array is reverse sorted.
      • Space: O(1) auxiliary (in-place).

        Merge Sort

        Merge Sort is a divide-and-conquer algorithm that splits the array into halves, sorts them, and merges the results.

        How does Merge Sort Algorithm Work?

        Merge Sort repeatedly divides the list into smaller halves until each subarray has one element, then merges those subarrays back together in sorted order.

        There are mainly four steps in the algorithm:

        1. Divide: Split the array into two halves.

        2. Conquer: Recursively sort each half.

        3. Merge: Combine two sorted halves into one sorted array.

        4. Repeat: Continue until the whole array is merged back.

        Big O Complexity
        • Best: O(n log n) for all cases.
        • Average: O(n log n) due to balanced splits and merges.
        • Worst: O(n log n) even for sorted input.
        • Space: O(n) auxiliary array for merging.

          Quick Sort

          Quick Sort is a sorting algorithm based on the Divide and Conquer that picks an element as a pivot and partitions the given array around the picked pivot by placing piviots in its correct position in the sorted array.

          How does Quicksort Algorithm Work?

          The visualization below uses the Lomuto partition scheme, since this partition algorithm is simple, where we assume the pivot element as the last element.

          There are mainly three steps in the algorithm:

          1. Choose a Pivot: Select an element from the array as the pivot. The choice of pivot can vary (e.g., first element, last element, random element, or median).

          2. Partition the Array: Re arrange the array around the pivot. After partitioning, all elements smaller than the pivot will be on its left, and all elements greater than the pivot will be on its right.

          3. Recursively Call: Recursively apply the same process to the two partitioned sub-arrays.

          4. Base Case: The recursion stops when there is only one element left in the sub-array, as a single element is already sorted.

          Big O Complexity
          • Best: O(n log n) when partitions are balanced.
          • Average: O(n log n) for random or mixed input.
          • Worst: O(n2) when the pivot is always min/max (already sorted).
          • Space: O(log n) average (recursion stack), O(n) worst case.
