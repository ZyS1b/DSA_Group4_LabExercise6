Quick Sort

Quick Sort is a sorting algorithm based on the Divide and Conquer that picks an element as a pivot and partitions the given array around the picked pivot by placing piviots in its correct position in the sorted array.

How does Quicksort Algorithm Work?

The visualization below uses the Lomuto partition scheme, since this partition algorithm is simple, where we assume the pivot element as the last element.

There are mainly three steps in the algorithm:

1. Choose a Pivot: Select an element from the array as the pivot. The choice of pivot can vary (e.g., first element, last element, random element, or median).

2. Partition the Array: Re arrange the array around the pivot. After partitioning, all elements smaller than the pivot will be on its left, and all elements greater than the pivot will be on its right.

3. Recursively Call: Recursively apply the same process to the two partitioned sub-arrays.

4. Base Case: The recursion stops when there is only one element left in the sub-array, as a single element is already sorted.

Big O Complexity
  • Best: O(n log n) when partitions are balanced.
  • Average: O(n log n) for random or mixed input.
  • Worst: O(n^2) when the pivot is always min/max (already sorted).
  • Space: O(log n) average (recursion stack), O(n) worst case.
